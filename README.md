# Black Ops II: Spectators Exponential Score
No longer dead weight! Each respawn dramatically boosts your score gains, turning every comeback into a valuable opportunity to finally contribute and make an impact.

Each spectator's score is scaled based on the current round. The score is calculated by taking the current round number to the power of 2, multiplying it by 20, and then rounding the result to the nearest 100. This allows players who join later in the game to start with a meaningful amount of score rather than being immediately overwhelmed by the difficulty of the current round. The scaled score does not put late-joining players on the same power level as players who have progressed through the entire game. Instead, it gives them enough survivability to have a fighting chance and remain useful to the team.
